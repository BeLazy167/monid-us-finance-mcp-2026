Financial Datasets-compatible US Financial Data API, backed by Monid

An independent, Monid-backed clone of the Financial Datasets API public interface: the same 27 MCP tool names, the same input parameters, and the same response shapes — at a fraction of the cost.

Pay only for what you call. Our live US-equities data routes SEC EDGAR, DefiLlama US equities, and Context.dev through Monid at measured per-call costs of $0.0006 – $0.0100 (mean $0.00101 across 51 priced calls), versus Financial Datasets’ Build at $200/month (100,000 requests included, $10 per additional 1,000) and Scale at $2,000/month (1,000,000 included, $5 per additional 1,000). Both plans work out to $0.002 per included request, so the difference that matters is the floor: theirs is $200 before the first call.

Bring your own Monid API key. Send it as X-API-KEY on every request — usage bills your own Monid wallet directly, we take no cut, and we never store your key. Get one at monid.ai.

Design principles

Contract parity — responses contain only Financial Datasets schema keys, in schema property order.

Zero mock data — no fabricated numbers. Unsourced fields are omitted, not guessed or nulled.

Auditable receipts — every Monid call, its run ID, and its measured cost are committed to receipts/ledger.jsonl.

Deterministic parsing — get_filing_items extracts canonical SEC sections with rule-based parsing; no LLM hallucination risk.
