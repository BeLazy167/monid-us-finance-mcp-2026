Insider Trades

Partial

Insider trading transactions for a US ticker from the SEC Form 4 feed — sales, purchases, prices, and transaction values.

MCP tool: get_insider_trades
GET/insider-trades

Description

Insider trading transactions for a US ticker from the SEC Form 4 feed — sales, purchases, prices, and transaction values. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL).
limitinteger10noNumber of trades to return (capped by the 15-row validated feed).
namestring—noSub-string match on the insider relationship text.
transaction_typestring—noFilter (e.g. purchase/sale).
form_typestring—noRejected (route does not report form types).
filing_date*string (YYYY-MM-DD)—nofiling_date, _gte, _lte filters.
cursorstring—noOpaque pagination token.

Response

FieldTypeNotes
insider_tradesarray<InsiderTrade>Trades, newest by filing date.
next_page_urlstring|nullPresent only when more records remain.
ticker/issuer/name/filing_date/transaction_datestringIdentity and dates.
transaction_type/transaction_sharesstring/integerDirection and quantity.
transaction_price_per_share/transaction_value/shares_owned_after_transactionnumberPrice, value, holdings after.
omitted fields—title, transaction_code, security_title, shares_owned_before_transaction: not reported by the feed.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://api.monid-finance-mcp.example/insider-trades?ticker=AAPL&limit=3' \
  -H 'X-API-KEY: <your-api-key>'

Honest notes

Capped at the validated 15-row SEC Form 4 feed (Financial Datasets allows 5000).
name is the full insider relationship text; form_type filtering answers bad_request.

Monid Finance MCP — an independent, Monid-backed Financial Datasets–compatible API. Not affiliated with or endorsed by Financial Datasets. Data sourced from SEC EDGAR, DefiLlama US equities, and Context.dev via Monid, measured per call.
