Earnings

Partial

Structured quarterly and annual earnings records composed from SEC 10-K and 10-Q filings: revenue, EPS, margins, and period-over-period changes.

MCP tool: get_earnings
GET/earnings

Description

Structured quarterly and annual earnings records composed from SEC 10-K and 10-Q filings: revenue, EPS, margins, and period-over-period changes. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL).
limitinteger1noNumber of earnings records to return.
cursorstring—noOpaque pagination token.

Response

FieldTypeNotes
earningsarray<EarningsRecord>Composed records, newest first.
next_page_urlstring|nullPresent only when more records remain.
ticker/report_period/source_type/filing_date/filing_url/accession_numberstringRequired identity fields.
fiscal_period/currency/filing_datetime/filing_windowstringFiscal and filing metadata.
quarterlyobjectRevenue, EPS, margins, changes, balance/cash context for the quarter.
annualobjectPresent on 10-K records.
signalsarrayNot produced by this server (no estimates/surprises sourced).

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://api.monid-finance-mcp.example/earnings?ticker=AAPL&limit=1' \
  -H 'X-API-KEY: <your-api-key>'

Honest notes

Estimates, surprise flags, and 8-K earnings releases are not sourced; signals are therefore absent from our records. The market-wide real-time earnings feed is not routed.

Monid Finance MCP — an independent, Monid-backed Financial Datasets–compatible API. Not affiliated with or endorsed by Financial Datasets. Data sourced from SEC EDGAR, DefiLlama US equities, and Context.dev via Monid, measured per call.
