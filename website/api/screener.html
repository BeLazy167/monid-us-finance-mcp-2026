Stock Screener

Partial

Screen stocks by company attributes via the Nasdaq screener — currently exchange and market-cap filters with the eq operator.

MCP tool: screen_stocks
POST/financials/search/screener

Description

Screen stocks by company attributes via the Nasdaq screener — currently exchange and market-cap filters with the eq operator. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
filtersarray<{field, operator, value}>—yesOne or more filter objects. Only {exchange, market_cap} with operator eq are executed.
limitinteger10noMaximum number of results.
currencystring—noAccepted for parity.
cursorstring—noOpaque pagination token.

Response

FieldTypeNotes
search_resultsarray<FinancialsSearchResult>Each: ticker, exchange, market_cap, last_sale, net_change, percent_change.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://monid-finance-api.fly.dev/financials/search/screener' \
  -H 'X-API-KEY: <your-api-key>' \
  -H 'Content-Type: application/json' \
  -d '{"filters": [{"field": "exchange", "operator": "eq", "value": "NASDAQ"}], "limit": 5}'
Response (real Nasdaq screener result for AAPL from the live smoke — $328.21)
{
  "search_results": [
    {
      "ticker": "AAPL",
      "exchange": "NASDAQ",
      "market_cap": "4789955817800",
      "last_sale": "328.21",
      "net_change": "-3.25",
      "percent_change": "-0.01"
    }
  ]
}

Honest notes

Only exchange and market_cap with eq are routed through the Nasdaq screener. Any other field or operator answers bad_request before spending.
