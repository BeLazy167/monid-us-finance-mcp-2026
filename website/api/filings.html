SEC Filings

Live

Recent SEC filings for a US company — 10-K, 10-Q, 8-K, 20-F, 6-K — with accession numbers and EDGAR URLs.

MCP tool: get_filings
GET/filings

Description

Recent SEC filings for a US company — 10-K, 10-Q, 8-K, 20-F, 6-K — with accession numbers and EDGAR URLs. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—noCompany ticker (e.g. AAPL).
cikstring—noCentral Index Key; accepted for parity but not routed.
filing_typearray<string>—noOne or more of 10-K, 10-Q, 8-K, 20-F, 6-K (validated).
limitinteger10noNumber of filings to return (record budget across pages).
cursorstring—noOpaque pagination token.

Response

FieldTypeNotes
filingsarray<Filing>Filings, newest first.
next_page_urlstring|nullPresent only when more records remain.
cik/accession_number/filing_typestringFiling identity.
report_date/filing_date/ticker/urlstringDates, ticker, and EDGAR URL.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://api.monid-finance-mcp.example/filings?ticker=AAPL&limit=3' \
  -H 'X-API-KEY: <your-api-key>'
