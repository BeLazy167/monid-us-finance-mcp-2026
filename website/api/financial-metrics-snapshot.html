Financial Metrics Snapshot

Live

Latest financial metrics for a US ticker from the live market summary: valuation multiples, margins, and key ratios at a point in time.

MCP tool: get_financial_metrics_snapshot
GET/financial-metrics/snapshot

Description

Latest financial metrics for a US ticker from the live market summary: valuation multiples, margins, and key ratios at a point in time. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL).
cikstring—noAccepted for parity; answered bad_request.

Response

FieldTypeNotes
snapshotobjectThe metric snapshot object.
ticker/market_cap/enterprise_valuestring/numberIdentity and size.
price_to_earnings_ratio/price_to_book_ratio/price_to_sales_ratio/enterprise_value_to_ebitda_rationumberValuation multiples.
gross_margin/operating_margin/net_marginnumberMargins (0–1 scale).
not yet sourced—return_on_equity, return_on_assets, inventory_turnover, days_sales_outstanding, growth fields, per-share fields, and other FinancialMetricSnapshot keys are omitted by this server.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://monid-finance-api.fly.dev/financial-metrics/snapshot?ticker=AAPL' \
  -H 'X-API-KEY: <your-api-key>'

Honest notes

The Financial Datasets schema carries ~40 snapshot fields; this server currently returns the 10-field subset above. Values shown are from the live AAPL smoke run.

Monid Finance MCP — an independent, Monid-backed Financial Datasets–compatible API. Not affiliated with or endorsed by Financial Datasets. Data sourced from SEC EDGAR, DefiLlama US equities, and Context.dev via Monid, measured per call.
