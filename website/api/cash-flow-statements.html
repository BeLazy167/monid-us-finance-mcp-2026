Cash Flow Statements

Live

Normalized cash flow statements for a US ticker: operating, investing, and financing cash flows, for annual, quarterly, or locally-derived TTM periods.

MCP tool: get_cash_flow_statement
GET/financials/cash-flow-statements

Description

Normalized cash flow statements for a US ticker: operating, investing, and financing cash flows, for annual, quarterly, or locally-derived TTM periods. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL).
periodstring: annual / quarterly / ttmannualnoCash flow granularity.
limitinteger4noNumber of statements to return.
cikstring—noAccepted for parity; answered bad_request.
report_period*string (YYYY-MM-DD)—noreport_period, _gte, _lte, _gt, _lt filters.
filing_date*string (YYYY-MM-DD)—nofiling_date, _gte, _lte, _gt, _lt filters.
cursorstring—noOpaque pagination token.

Response

FieldTypeNotes
cash_flow_statementsarray<CashFlowStatement>Normalized statements, newest first.
next_page_urlstring|nullPresent only when more records remain.
identitystringticker, report_period, fiscal_period, period, currency, accession_number, form_type, filing_url, filing_date, filing_datetime.
net_income … free_cash_flownumberLine items in schema order; unsourced fields omitted.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://api.monid-finance-mcp.example/financials/cash-flow-statements?ticker=AAPL&period=ttm&limit=1' \
  -H 'X-API-KEY: <your-api-key>'

Honest notes

No captured live receipt exists for full cash-flow line items at doc time. The endpoint returns them from the DefiLlama statements matrix; TTM derives locally from four consecutive quarters. Identity fields above are real, from the FY2025 10-K smoke run.
