Income Statements

Live

Normalized income statements for a US ticker: revenue, expenses, and net income for annual, quarterly, or trailing-twelve-month periods.

MCP tool: get_income_statement
GET/financials/income-statements

Description

Normalized income statements for a US ticker: revenue, expenses, and net income for annual, quarterly, or trailing-twelve-month periods. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL). Required at runtime; cik lookup is not routed.
periodstring: annual / quarterly / ttmannualnoStatement granularity.
limitinteger4noNumber of statements to return (record budget across pages).
cikstring—noAccepted for contract parity; answered bad_request.
report_periodstring (YYYY-MM-DD)—noExact report period filter.
report_period_gtestring (YYYY-MM-DD)—noReport period at or after this date.
report_period_ltestring (YYYY-MM-DD)—noReport period at or before this date.
report_period_gtstring (YYYY-MM-DD)—noReport period strictly after this date.
report_period_ltstring (YYYY-MM-DD)—noReport period strictly before this date.
filing_datestring (YYYY-MM-DD)—noExact filing date filter (needs filings join).
filing_date_gtestring (YYYY-MM-DD)—noFiling date at or after this date.
filing_date_ltestring (YYYY-MM-DD)—noFiling date at or before this date.
filing_date_gtstring (YYYY-MM-DD)—noFiling date strictly after this date.
filing_date_ltstring (YYYY-MM-DD)—noFiling date strictly before this date.
cursorstring—noOpaque pagination token (base64url).

Response

FieldTypeNotes
income_statementsarray<IncomeStatement>Normalized statements, newest first.
next_page_urlstring|nullPresent only when more records remain.
ticker/report_period/fiscal_periodstringCompany identity + fiscal labeling.
period/currencystringannual|quarterly|ttm; USD.
revenue … weighted_average_shares_dilutednumberLine items in schema order; unsourced fields omitted.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://api.monid-finance-mcp.example/financials/income-statements?ticker=AAPL&period=annual&limit=1' \
  -H 'X-API-KEY: <your-api-key>'
