Screener Filters

Partial

List the executable stock-screener filters and operators supported by the Nasdaq route.

MCP tool: list_stock_screener_filters
GET/financials/search/screener/filters

Description

List the executable stock-screener filters and operators supported by the Nasdaq route. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
———noNo parameters. Static, zero-cost catalog.

Response

FieldTypeNotes
metrics.companyarray<{field,operators,values}>exchange (NASDAQ, NYSE, AMEX) and market_cap (mega … nano), each with operator eq.
operatorsarray<string>["eq"]

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://monid-finance-api.fly.dev/financials/search/screener/filters' \
  -H 'X-API-KEY: <your-api-key>'

Honest notes

Lists only the executable filters, not the full Financial Datasets catalog. Returns at zero cost.
