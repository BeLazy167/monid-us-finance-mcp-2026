Price Snapshot

Live

Latest stock price for a US ticker with 1-day change, from the live market summary.

MCP tool: get_stock_price
GET/prices/snapshot

Description

Latest stock price for a US ticker with 1-day change, from the live market summary. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL).

Response

FieldTypeNotes
snapshotobjectThe price snapshot object.
pricenumberLatest price.
tickerstringRequested ticker.
day_change/day_change_percentnumber1-day absolute and % change.
timestringSnapshot timestamp.
time_millisecondsintegerNot emitted by this server (schema-legal omission).

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://api.monid-finance-mcp.example/prices/snapshot?ticker=AAPL' \
  -H 'X-API-KEY: <your-api-key>'
Response (AAPL observation of 2026-09-03 from the screener smoke; day_change consistent with net change)
{
  "snapshot": {
    "price": 328.21,
    "ticker": "AAPL",
    "day_change": -3.25,
    "day_change_percent": -0.01,
    "time": "2026-09-03"
  }
}

Honest notes

price and day-change values shown correspond to the same AAPL observation ($328.21) captured in the live screener smoke on 2026-09-03.
This is a point-in-time snapshot, not a real-time stream.
