Company Facts

Live

Basic company profile for a US ticker — currently ticker and name from the DefiLlama US company catalog.

MCP tool: get_company_facts
GET/company/facts

Description

Basic company profile for a US ticker — currently ticker and name from the DefiLlama US company catalog. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL).
cikstring—noAccepted for parity; answered bad_request (only ticker lookup routed).

Response

FieldTypeNotes
company_factsobjectCompany facts object.
ticker/namestringIdentity and legal name.
not yet sourced—cik, industry, sector, exchange, is_active, location, sec_filings_url, sic_*: omitted until the catalog provides them.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://api.monid-finance-mcp.example/company/facts?ticker=AAPL' \
  -H 'X-API-KEY: <your-api-key>'
Response (real AAPL facts from the live smoke — ticker and name)
{
  "company_facts": {
    "ticker": "AAPL",
    "name": "Apple Inc."
  }
}

Honest notes

Company facts currently source ticker and name only; cik lookup answers bad_request.

Monid Finance MCP — an independent, Monid-backed Financial Datasets–compatible API. Not affiliated with or endorsed by Financial Datasets. Data sourced from SEC EDGAR, DefiLlama US equities, and Context.dev via Monid, measured per call.
