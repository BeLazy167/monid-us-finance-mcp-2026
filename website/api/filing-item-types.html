Filing Item Types

Live

List the supported SEC filing item catalog for 10-K, 10-Q, and 8-K forms, with canonical items and their SEC titles.

MCP tool: list_filing_item_types
GET/filings/items/types

Description

List the supported SEC filing item catalog for 10-K, 10-Q, and 8-K forms, with canonical items and their SEC titles. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
filing_typestring: 10-K / 10-Q / 8-K—noRestrict the catalog to one form; omit for all.

Response

FieldTypeNotes
10-K / 10-Q / 8-Karray<{name,title,description}>Item catalog per form.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://api.monid-finance-mcp.example/filings/items/types?filing_type=10-K' \
  -H 'X-API-KEY: <your-api-key>'
