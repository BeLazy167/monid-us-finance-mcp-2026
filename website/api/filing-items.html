SEC Filing Items

Live

Extract specific sections from a 10-K, 10-Q, or 8-K — e.g. Item 1A Risk Factors — using deterministic rule-based parsing of the filing document.

MCP tool: get_filing_items
GET/filings/items

Description

Extract specific sections from a 10-K, 10-Q, or 8-K — e.g. Item 1A Risk Factors — using deterministic rule-based parsing of the filing document. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL).
filing_typestring: 10-K / 10-Q / 8-K—yesFiling form.
yearinteger—yesFiling year.
quarterinteger—noFiling quarter (10-Q/8-K).
itemstring—noItem number (e.g. Item-1A, Item-7).
accession_numberstring—noExact accession; else derived from the filings index.
include_exhibitsbooleanfalsenoAccepted for parity; answered bad_request when true.

Response

FieldTypeNotes
resource/ticker/filing_type/accession_number/year/quarterstring/integerRequest identity.
itemsarray<FilingItem>Each: number, name, text.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://monid-finance-api.fly.dev/filings/items?ticker=AAPL&filing_type=10-K&year=2024&item=Item-1A' \
  -H 'X-API-KEY: <your-api-key>'
Response (accession 0000320193-24-000123, the FY2024 10-K used in the smoke)
{
  "resource": "filing_item",
  "ticker": "AAPL",
  "filing_type": "10-K",
  "accession_number": "0000320193-24-000123",
  "year": 2024,
  "quarter": null,
  "items": [
    {
      "number": "Item-1A",
      "name": "Risk Factors",
      "text": "\u2026 extracted section body (16,053 characters for Item-1 of the FY2025 10-K in our smoke). Elided here."
    }
  ]
}

Honest notes

Gate A smoke extracted a 16,053-character Item-1 body from the FY2025 10-K (accession 0000320193-25-000079); Item-1A was extracted from the FY2024 10-K. Body text is elided in this doc example.
Exhibits are not sourced; include_exhibits=true answers bad_request at zero cost.
