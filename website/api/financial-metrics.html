Financial Metrics

Partial

Historical financial metrics and ratios for a US ticker — margins, returns, turnover, liquidity, growth, and per-share values, per annual/quarterly/ttm period.

MCP tool: get_financial_metrics
GET/financial-metrics

Description

Historical financial metrics and ratios for a US ticker — margins, returns, turnover, liquidity, growth, and per-share values, per annual/quarterly/ttm period. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL).
periodstring: annual / quarterly / ttmannualnoMetrics granularity.
limitinteger4noNumber of periods to return.
cikstring—noAccepted for parity; answered bad_request.
report_period*string (YYYY-MM-DD)—noreport_period, _gte, _lte, _gt, _lt filters.
filing_date*string (YYYY-MM-DD)—nofiling_date, _gte, _lte, _gt, _lt filters.
cursorstring—noOpaque pagination token.

Response

FieldTypeNotes
financial_metricsarray<FinancialMetric>Metrics per period, newest first.
ticker/report_period/fiscal_period/periodstringPeriod identity.
gross_margin/operating_margin/net_marginnumberRatios (0–1 scale).
return_on_equity/return_on_assetsnumberEnding-balance based.
inventory_turnover/receivables_turnover/days_sales_outstandingnumberAverage-balance based.
current_ratio/quick_ratio/debt_to_equity…numberLiquidity and leverage.
revenue_growth/earnings_per_share_growth…numberGrowth set.
earnings_per_share/book_value_per_share/free_cash_flow_per_sharenumberPer-share values.
validation fields—enterprise_value, price-to-* ratios, EV multiples, free_cash_flow_yield, peg_ratio, return_on_invested_capital, currency, filing_datetime: omitted (not sourceable without fabricating data).

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://monid-finance-api.fly.dev/financial-metrics?ticker=AAPL&period=annual&limit=1' \
  -H 'X-API-KEY: <your-api-key>'
Response (margins derived from the real FY2025 income statement; ROE/DSO/inventory turnover from the live smoke)

Honest notes

Historical per-period market values cannot be sourced, so valuation fields are omitted rather than estimated.
TTM rows omit filing identity (accession_number, form_type, filing_url, filing_date) because a TTM window spans filings.

Monid Finance MCP — an independent, Monid-backed Financial Datasets–compatible API. Not affiliated with or endorsed by Financial Datasets. Data sourced from SEC EDGAR, DefiLlama US equities, and Context.dev via Monid, measured per call.
