Stock Prices

Live

Historical OHLCV price bars for a US ticker, aggregated locally to day, week, month, or year intervals.

MCP tool: get_stock_prices
GET/prices

Description

Historical OHLCV price bars for a US ticker, aggregated locally to day, week, month, or year intervals. It mirrors the Financial Datasets public interface; see the compatibility contract at docs/compatibility.md in the repo.

Parameters

ParameterTypeDefaultRequiredNotes
tickerstring—yesCompany ticker (e.g. AAPL).
intervalstring: day / week / month / yeardaynoBar interval.
start_datestring (YYYY-MM-DD)—noInclusive start date.
end_datestring (YYYY-MM-DD)—noInclusive end date.
cursorstring—noOpaque pagination token (100-record pages).

Response

FieldTypeNotes
tickerstringRequested ticker.
pricesarray<Price>Ascending bars: open, close, high, low, volume, time.
next_page_urlstring|nullPresent only when more records remain.

Unsuccessful calls return the Financial Datasets {"error", "message"} shape (e.g. bad_request, not_found, upstream_error). Fields the backing sources cannot honestly provide are omitted, never fabricated.

Examples

Request
curl -s 'https://api.monid-finance-mcp.example/prices?ticker=AAPL&interval=day&start_date=2026-08-25&end_date=2026-08-28' \
  -H 'X-API-KEY: <your-api-key>'

Honest notes

Historical daily data with local aggregation only — not real-time. time is the bar end date in UTC.

Monid Finance MCP — an independent, Monid-backed Financial Datasets–compatible API. Not affiliated with or endorsed by Financial Datasets. Data sourced from SEC EDGAR, DefiLlama US equities, and Context.dev via Monid, measured per call.
