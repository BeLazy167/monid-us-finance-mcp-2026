Response contract

Success responses contain only Financial Datasets schema keys in schema property order. All failures return {"error": <code>, "message": <detail>}. Error codes: bad_request, not_found, invalid_cursor, upstream_error, timeout, schema_drift, not_implemented. Pagination: limit is a total record budget, cursor is an opaque base64url token, next_page_url appears only when more records remain (10 per page; 100 for prices).

Provenance, measured cost, and warnings never appear inside responses; they are committed to receipts/ledger.jsonl per Monid call.

Monid Finance MCP — an independent, Monid-backed Financial Datasets–compatible API. Not affiliated with or endorsed by Financial Datasets. Data sourced from SEC EDGAR, DefiLlama US equities, and Context.dev via Monid, measured per call.
