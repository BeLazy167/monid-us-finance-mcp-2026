MCP Server

A streamable-HTTP MCP server exposing all 27 Financial Datasets tool names with matching parameters.

Connection details

FieldTypeNotes

AuthX-API-KEY headerSend your Monid API key on every request.

Connect from Claude

claude_desktop_config.json
{
  "mcpServers": {
    "monid-finance": {
      "url": "https://api.monid-finance-mcp.example/mcp",
      "headers": { "X-API-KEY": "<your-api-key>" }
    }
  }
}

Connect from Cursor

Cursor settings → MCP → Add new global MCP server, then paste:

.cursor/mcp.json (or global)
{
  "mcpServers": {
    "monid-finance": {
      "url": "https://api.monid-finance-mcp.example/mcp",

  }
}

Connect from Claude Code

Terminal
claude mcp add monid-finance --transport http https://api.monid-finance-mcp.example/mcp --header "X-API-KEY: <your-api-key>"
All three clients speak streamable HTTP. The header carries your key; keep it out of command logs and shell history (use a credential file or env var where possible).
