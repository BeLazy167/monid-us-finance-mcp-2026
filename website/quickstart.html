Quickstart

Authenticate, hit the REST facade, or connect the MCP server — in under two minutes.

1. Get your API key

Create an account and grab your API key from your monid.ai dashboard. This is your own key, not ours: authenticate every request by sending it in the X-API-KEY header, and every call bills your own Monid wallet directly. We never store or log it.

Terminal
export MONID_API_KEY=<your-api-key>

2. Choose a base URL

Terminal
export BASE_URL=https://monid-finance-api.fly.dev

This is the documented facade base. The live MCP server is served from https://monid-finance-api.fly.dev/mcp.

4. Connect the MCP server

https://monid-finance-api.fly.dev/mcp is a streamable-HTTP MCP endpoint. Set the X-API-KEY header so the server can authenticate you.

Claude Desktop

claude_desktop_config.json
{
  "mcpServers": {
    "monid-finance": {
      "url": "https://monid-finance-api.fly.dev/mcp",
      "headers": { "X-API-KEY": "<your-api-key>" }
    }
  }
}

5. Python example

Python
import requests

BASE_URL = "https://monid-finance-api.fly.dev"
API_KEY = "<your-api-key>"

headers = {"X-API-KEY": API_KEY}

def income_statements(ticker: str, period: str = "annual", limit: int = 4):
    resp = requests.get(
        f"{BASE_URL}/financials/income-statements",
        params={"ticker": ticker, "period": period, "limit": limit},
        headers=headers,
    )
    resp.raise_for_status()
    return resp.json()

# AAPL FY2025 annual income statement
data = income_statements("AAPL", "annual", 1)
record = data["income_statements"][0]
print(record["report_period"], record["revenue"], record["earnings_per_share"])
# 2025-09-27 416161000000.0 7.49
